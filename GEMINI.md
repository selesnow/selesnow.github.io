# alexey-seleznev.pro

Личный сайт Алексея Селезнёва (GitHub Pages, ветка `master`, домен из `CNAME`).

## ⚠️ Перед началом любой работы — `git pull`

GitHub Actions (`.github/workflows/update-stats.yml`) каждый день в 06:00 UTC коммитит
в `master` свежие счётчики скачиваний и звёзд и пересобирает страницы. Поэтому локальная копия
почти всегда отстаёт от удалённой.

1. Первым делом выполни `git pull` (при незакоммиченных изменениях — `git pull --rebase --autostash`).
2. Если pull завершился конфликтом, не разрешай его вслепую: в файлах счётчиков
   (`assets/stats.json`, `_build/data/package_stats.json`, сгенерированные страницы) бери версию
   с удалённого репозитория и пересобирай страницы, а в остальных файлах сначала спроси пользователя.
3. Коммить и пушь только по просьбе пользователя.

## Устройство проекта

- `index.html` — одностраничный лендинг. **Правится только вручную**, генератор его не трогает.
  Пользователю лендинг очень нравится: меняй в нём только то, о чём просят.
- Внутренние страницы `opensource/`, `courses/`, `videos/`, `talks/`, `articles/`, `interviews/`
  (`index.html` в каждой) **генерируются** скриптом `_build/build.py` из JSON в `_build/data/`.
  Не правь их HTML руками — изменения пропадут при следующей сборке (в том числе ночной).
  Меняй данные в `_build/data/*.json` или шаблоны в `_build/build.py`, затем запускай
  `python _build/build.py`.
- `_build/` не публикуется: Jekyll игнорирует каталоги, начинающиеся с `_`.
- `assets/site.css`, `assets/site.js` — общие стили и скрипт внутренних страниц;
  стили повторяют лендинг (Tailwind CDN, bento-glass карточки, фон Vanta.js).
- `assets/stats.json` — публичный снимок счётчиков (cranlogs + GitHub API), его читают лендинг
  и `/opensource/`. Обновляется ночным workflow или командой `python _build/build.py --stats-only`.
- `assets/logos/` — логотипы пакетов, `assets/services/` — обложки сервисов.
- Остальные каталоги в корне (`r4excel_users/`, `library/`, `news/` и др.) — старые проекты, не трогать.

## Правила контента

- Весь видимый текст трёхъязычный: `<span class="ru-text">…</span><span class="ua-text">…</span><span class="en-text">…</span>`.
  В генераторе для этого функции `T(ru, ua, en)` и `tr({...})`. Язык хранится в `localStorage.preferredLang`.
- Ссылки на курсы и документацию пакетов — через домен `https://alexey-seleznev.pro/...`, не `selesnow.github.io`.
- Битые внешние ссылки на статьи/интервью заменяй копией в блоге https://alexeyseleznev.wordpress.com/
  (карточка помечается `"via": "blog"`). Не нашёл копию — не публикуй мёртвую ссылку, сообщи пользователю.
- Пакеты ryandexdirect, rym, rvkstat, rmytarget помечены как архивные (`"archived": true`);
  пояснений о причинах архивации на сайте быть не должно.
- Футер общий для всего сайта: шаблон `footer(prefix)` в `_build/build.py` (колонки «Сайт»,
  «R4marketing и публикации», «Контакты»). Колонка «Сайт» строится из списка `PAGES`.
  На лендинге стоит вывод `footer('')`: после изменения шаблона замени блок `<!-- FOOTER -->`…`</footer>`
  в `index.html` (`python -c "import sys; sys.path.insert(0,'_build'); import build; print(build.footer(''))"`).
- Новую внутреннюю страницу добавляй в `PAGES`, в `sitemap.xml` и обновляй футер лендинга.

## Проверка

Локальный сервер: `python -m http.server 8765` из корня репозитория (YouTube-плеер на `file://` не работает).
Скриншоты: headless Chrome с `--screenshot`; у headless-режима минимальная ширина окна около 500px,
поэтому мобильная обрезка на скриншотах — артефакт, а не баг вёрстки.
