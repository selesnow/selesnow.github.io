Статья – дайджест зимних обновлений R клиентов для работы с API Яндекс Директ, Facebook и Вконтакте.

Честно говоря за зиму было не так много обновлений, но тем не менее возможности некоторых пакетов было довольно значительно расширены.

![Картинки по запросу зимний дайджест](https://i0.wp.com/vnimatelnostdetyam.com/wp-content/uploads/2016/12/8-910x480.jpg)

Первое о чём хотелось бы рассказать, это то, что у всех пакетов появилось единое хранилище документации и новостей, найти его можно по этой [ссылке](https://selesnow.github.io/).

## Обновления [ryandexdirect](https://github.com/selesnow/ryandexdirect/)

*ryandexdirect – пакет на языке R, для загрузки статистики из Яндекс Директ и Яндекс Метрики, и управления рекламными кампаниями.*

- Релиз версии 2.4.4 включил в себя доработку функции yadirGetCampaignList, в которую были добавлены дополнительные аргументы для фильтрации списка запрашиваемых рекламных кампаний по состоянию, типу, статусу кампании, статусу оплаты, а так же названия всех аргументов теперь необходимо указывать с заглавной буквы, подробнее об этом обновлении можно узнать по [ссылке](https://github.com/selesnow/ryandexdirect/releases/tag/2.4.4).
- В версии 2.5.0 была добавлена возможность остановки и возобновления показов на уровне объявлений, ключевых слов и рекламных кампаний, и была значительно ускорена работа основной функции пакета yadirGetReport, подробности [тут](https://github.com/selesnow/ryandexdirect/releases/tag/2.5.0).

## Обновления [rfacebookstat](https://github.com/selesnow/rfacebookstat/)

*rfacebook- пакет на языке R, для загрузки статистики из рекламных кабинетов и бизнес менеджеров в Facebook, и управления рекламными кампаниями.*

- Первым зимним обновлением был релиз версии 1.4.6 и 1.5.2, в котором была значительно доработана функция fbGetMarketingStat, наибольшим образом это отразится на пользователях имеющих минимальный уровень доступа к API Facebook, более подробно можно узнать по [ссылке](https://github.com/selesnow/rfacebookstat/releases/tag/1.4.6) и [тут](https://github.com/selesnow/rfacebookstat/releases/tag/1.5.2).
- В версии 1.6.1 появились функции с помощью которых вы можете добавлять и удалять доступ различным пользователям Facebook к рекламным аккаунтам, детальную информацию можно посмотреть [тут](https://github.com/selesnow/rfacebookstat/releases/tag/1.6.1).

## Обновления [rvkstat](https://github.com/selesnow/rvkstat/)

*rvkstat- пакет на языке R, для загрузки данных из рекламных аккаунтов, сообществ, пользователей в социальной сети Вконтакте.*

- Начиная с версии 2.1.4 функция  vkGetAdPostsReach может обрабатывать неограниченное количество ids кампаний или объявлений, ранее можно было запрашивать данные максимум по 100 объявлениям, информация о релизе доступна по [ссылке](https://github.com/selesnow/rvkstat/releases/tag/2.1.4).
- В версии 2.3.0 добавлена функция vkGetAdsLayout, с помощью которой можно получить описание внешнего вида ркламных объявлений из рекламного аккаунта Вконтакте, для получения детальной информации идём по [ссылке](https://github.com/selesnow/rvkstat/releases/tag/2.3.0).
