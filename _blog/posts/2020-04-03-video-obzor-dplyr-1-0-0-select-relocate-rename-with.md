`dplyr` – один из наиболее популярных пакетов для манипуляции данных на языке R.

В мае ожидается релиз `dplyr 1.0.0`, после чего интерфейс пакета практически не будет меняться. На данный момент новые функционал можно попробовать установив его dev версию.

Хедли Викхем по этому поводу начал публикацию серии статей, которые должны постепенно познакомить многочисленных пользователей `dplyr` с его новым функционалом к моменту официального релиза.

![](https://i0.wp.com/img.netpeak.ua/alsey/158590564871_kiss_54kb.png)

Я снял 10 минутный [видео](https://youtu.be/k4v5cfLuUAQ) обзор по мотивам недавно опубликованной [статьи](https://www.tidyverse.org/blog/2020/03/dplyr-1-0-0-select-rename-relocate/) из этой серии.

В видео вы познакомитесь с возможностями обновлённой функциями `select()`, и несколькими новыми функциями: `relocate()`, `rename_with()`, `any_of()`, `all_of()`.

Если видео получит хороший отклик по мере наличия времени сниму такие же обзоры и по следующим статьям из этой серии.
