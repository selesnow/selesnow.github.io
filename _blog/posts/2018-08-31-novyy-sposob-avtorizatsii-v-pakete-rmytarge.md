Пакет rmytarget получил доступ к авторизации по схеме Code Grant, теперь работать через функции данного пакета вы можете даже если у вас нет доступа к API MyTarget.

Теперь для работы с API MyTarget через rmytarget нет необходимости запрашивать доступ к API, т.к. пакет получил доступ к схеме авторизации Code Grant, которая позволяет вам использовать функции пакета разрешив доступ к данным своего аккаунта. При первой авторизации ваши учётные данные будут сохранены в локальный файл .mytar.Auth.RData, и далее будет загружаться из этого файла.

API myTarget даёт возможность получить только 5 токенов для одного аккаунта, поэтому не теряйте токены, по умолчанию файл в котором хранится учётные данные будет сохранён в вашей рабочей директории, (узнать какая папка является рабочей можно с помощью команды getwd()), но вы можете указать любую другую папку с помощью аргумента token\_path.

С полной документацией по работе с пакетом можно ознакомится [тут](https://selesnow.github.io/rmytarget).
