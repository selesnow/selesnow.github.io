Коммуникации с клиентами неотъемлемая часть любого бизнеса, наиболее важно это для B2B сегмента, и в целом для любого бизнеса с высоким LifeTime Value,  у меня была задача автоматизировать процесс формирования списка клиентов для обзвона для передачи его ответственному сотруднику.

![Картинки по запросу обзвон клиентов](../images/avtomatizatsiya-protsessa-kommunikatsii-r-4y-m4f-x8-9063d2e5.webp)

1. Задача.

Сотруднику ответственному за прозвон клиентов еженедельно нужен список активных клиентов для прозвона, список составляется следующим образом, от момента начала работ по второму этапу необходимо звонить клиенту каждые 3 месяца, соответственно необходимо выводить список клиентов для прозвона на текущей неделе, со всей дополнительной информацией.

- Название предприятия
- ФИО клиента
- День рождения клиента
- Ссылка на контактную информацию клиента в пупе
- Страна клиента
- Домен
- Услуга
- PM по проект услуге
- Дата начала второго этапа
- Дата прозвона

2. Решение.

2.1. Инструменты которые использовались для реализации.

- Язык R – собственно сердце этой автоматизации.
- MySQL – база в которой хранится вся необходимая информация для формирования списка клиентов для обзвона.
- Google Таблицы – сюда полученный список собирается для внесения комментариев по результатам обзвона.

2.2. Схема работы готового решения.

![](../images/avtomatizatsiya-protsessa-kommunikatsii-8f46cb7e894d5aa8e321-b8e8e594.webp)

- Вся необходимая информация хранится в нашей внутренней ERP/CRM системе, процесс запускается автоматически раз в неделю по расписанию в понедельник.
- R Script отправляет SQL запрос в базу данных и получает список активных клиентов с датой начала работ по второму этапу.
- R вычисляет ближайшую дату прозвона клиенту согласно поставленной задачи (т.е. по активным клиентам каждые 3 месяца после начала второго этапа, список прозвонов формируется на ближайшую неделю), и формирует список для прозвона.
- Сформированный список в отправляется письмом на почту Nastasia.
- Готовым списком также дополняется готовый докс для обзвонов, в которой Nastasia вносит информацию по результатам прозвона клиентов.

3. Результат.  
  
Оценить результат внедрения этой автоматизация в часах либо в деньгах очень сложно т.к. в ручном режиме эту операцию даже не пробовали выполнять, т.к. в ручном режиме это явно не эффективно и очень трудоёмко.
