# Проверка сайта

Верстка сайта зависит от ширины окна: Tailwind-классы вроде `2xl:` включаются только от 1536 px. Меню, которое выглядело
аккуратно при 1440 px, на мониторе 1920 px «разъезжалось», и это не было видно, пока не снимали оба размера.
Поэтому проверка = пересборка + глаза при двух ширинах + проверка адресов.

## Порядок

1. **Пересобери**: `python _build/build.py` (нужен Node.js для Tailwind). Забытая пересборка — частая причина «класс не работает»:
   `assets/tailwind.css` строится заранее из классов, найденных в страницах, шаблонах и JS.
2. **Сними страницы** скриптом, который сам поднимает сервер на свободном порту и гасит его в конце:

   ```
   PYTHONUTF8=1 python .claude/skills/site-check/scripts/shots.py blog courses -w 1440 1920
   ```

   - Пути пиши **без ведущего слэша** (`blog`, `courses`), главная — `home`. Git Bash превращает `/blog/` в `C:/Program Files/Git/blog/`.
   - Скрипт печатает пути к PNG — открой их инструментом Read и действительно посмотри. Какие страницы снимать:
     те, что менял, плюс как минимум главная и одна внутренняя (общая шапка и футер ломаются сразу везде).
   - Высота по умолчанию 900 px, для длинных страниц добавь `-H 1600`.
   - Если снимок показывает анимацию «в полёте» (полупрозрачные блоки), это AOS — не баг.
   - Ширина headless-Chrome не меньше ~500 px, поэтому «обрезка» на мобильном размере — артефакт, а не ошибка вёрстки.
3. **Что искать глазами**: расстояния в меню (должно быть компактно, как на главной), наезд пунктов на логотип и переключатель языка,
   обрезанные заголовки и фото, пустые карточки, сломанные картинки, пункт меню «Блог»/активная страница подсвечены.
4. **Проверь адреса** (после пуша и сборки Pages — по боевому сайту; до пуша можно с `--base http://localhost:ПОРТ`, если сам поднял сервер):

   ```
   PYTHONUTF8=1 python .claude/skills/site-check/scripts/check_sitemap.py
   ```

   Код возврата 1 и список адресов, если что-то не 200. Страницу `ads/` в sitemap добавлять не нужно — она открывается только по прямой ссылке.
5. **Доложи пользователю**: что проверено (какие страницы и ширины), что нашёл, и честно — чего не проверял
   (например, 1920 px на странице, которую не снимал).

## Заметки

- Порт 8765 может быть занят сервером пользователя (например, его собственным `nocache_server.py`). Такой процесс не убивай:
  скрипт берёт свободный порт сам. Если запускаешь свой `python -m http.server`, после проверки останови его PID-ом
  (`Get-CimInstance Win32_Process` → `Stop-Process -Id`), `pkill` в Git Bash нет.
- YouTube-плеер на `file://` не работает — всегда проверяй через HTTP-сервер.
- Скриншоты лежат во временной папке, в репозиторий их не клади.
