Язык R для интернет-маркетинга

Автоматизация рутины маркетолога и веб-аналитика: от основ синтаксиса до Telegram-ботов. Курс создан в 2018 году вместе с NeedForData и Netpeak и с тех пор неоднократно дополнен. Три модуля, видеоуроки с конспектами и материалы к каждому уроку.

О курсе · 3 мин

Чему вы научитесь

  • Основы синтаксиса R, строки, даты, циклы и функции
  • Работа с таблицами: dplyr, data.table, tidyr, SQL
  • R-скрипты внутри Power BI
  • Загрузка данных из API рекламных систем и веб-аналитики
  • Парсинг сайтов и HTTP-запросы
  • Google Таблицы, ggplot2 и базы данных
  • Рассылка отчётов, запуск скриптов по расписанию и Telegram-боты

Для интернет-маркетологов и веб-аналитиков без опыта программирования.
