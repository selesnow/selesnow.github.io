Вебинар: Как маркетологу избавиться от рутины с помощью языка R и наконец-то заняться маркетингом (WebPromo Experts)

23 ноября 201823 листопада 201823 Nov 2018 2 мин чтения2 хв читання2 min read RU
Материал опубликован в 2018 году — описанные инструменты и интерфейсы могли измениться.Матеріал опубліковано у 2018 році — описані інструменти та інтерфейси могли змінитися.Published in 2018 — the tools and interfaces described may have changed since.

Digital-маркетологи делают сотни рутинных действий каждый день, в то время как их доход очень часто напрямую зависит от соотношения “количество проектов / качество работы”. Я расскажу, как с помощью R языка программирования, API интерфейсов рекламных систем и пакетных решений для обработки данных, можно быстро и качественно автоматизировать рутинные процессы и наконец-то заняться маркетингом.

На вебинаре Вы узнаете:

  • Что такое язык R;
  • Что такое API;
  • Что такое пакеты в R;
  • Как работать с API Яндекс Директ с помощью пакета ryandexdirect;
  • Как работать с API Google Ads с помощью пакета RAdwords;
  • Как работать с API Google Analytics c помощью пакета RGA

Данный вебинар будет интересен:

  • Интернет-маркетологам;
  • Владельцам бизнеса и руководителям;
  • Начинающим специалистам.
