Все обновления пакетов ryandexdirect, rfacebookstat и rvkstat за осень 2017.

1 декабря 20171 грудня 20171 Dec 2017 5 мин чтения5 хв читання5 min read RU
Материал опубликован в 2017 году — описанные инструменты и интерфейсы могли измениться.Матеріал опубліковано у 2017 році — описані інструменти та інтерфейси могли змінитися.Published in 2017 — the tools and interfaces described may have changed since.

В этой статье я собрал все доработки R клиентов ryandexdirect, rfacebookstat и rvkstat за осень 2017 года.

В каждом из трёх пакетов был ряд значительных доработок, о которых и пойдёт речь ниже:

ryandexdirect

ryandexdirect – R клиент для работы с API Яндекс. Директ версий Live 4 и 5, а так же для работы с API Яндекс. Метрики.

Репозиторий с подробным описанием функционала находится тут.

Наиболее популярный из разработанных мной пакетов, почти 50% от посещений 7 опубликованных мной репозиториев на GitHub приходятся именно на ryandexdirect.

Доработки и релизы ryandexdirect за осень 2017:
  • Добавлены 3 функции: yadirGetAds, yadirGetKeyWords, yadirGetAdGroups (релиз версии 2.2.0. от 13 сентября 2017 года). С помощью этих функций вы можете получить список групп объявлений, объявлений, ключевых слов с различными их параметрами.
  • Доработана функция yadirGetCampaignList (релиз версии 2.2.0. от 13 сентября 2017 года), теперь она работает без каких либо ограничений на количество возвращаемых рекламных кампаний, теперь вы можете получить полный список рекламных кампаний даже из аккаунтов в которых более 10 000 рекламных кампаний.
  • В пакет ryandexdirect добавлена функция yadirGetMetrikaGAData (релиз версии 2.3.0. от 21 сентября 2017 года.) предназначенная для работы с API Яндекс Метрики совместимым с Google Analytics Core Reporting API (v3) и даёт возможность использовать привычные параметры запросов при сборе статистики, если ранее вы работали с Google Analytics Core Reporting API (v3).
  • Добавлена функция yadirGetBalance, с помощью которой можно получить все параметры общего счёта включая текущий остаток средств. (Релиз версии 2.4.0 от 4 октября 2017 года).
  • Векторизация функции yadirGetReport, это означает что в аргумент Login можно на вход давать вектор логинов, после чего функция соберёт данные из всех рекламным аккаунтов переданных в векторе логинов. (Релиз версии 2.4.1. от 1 ноября 2017 года).
  • Доработана функция yadirGetKeyWords, в результирующей таблице, которую возвращает данная функция добавлены поля ProductivityValue и ProductivityReferences. Отдельного релиза под эту доработку небыло, подробности можно узнать на facebook.
  • Пакет ryandexdirect теперь можно установить на Linux, Unix и macOs, для этого воспользуйтесь командой install_github(‘selesnow/ryandexdirect’, subdir = “utf8”).

rfacebookstat

rfacebookstat– R клиент для загрузки данных из бизнес менеджера и рекламных кабинетов Facebook в R.

Репозиторий пакета rfacebookstat, с подробным описанием всех доступных в пакете функций доступен по ссылке.

Доработки и релизы rfacebookstat за осень 2017:
  • 29 сентября 2017 года была переписана схема аутентификации и получения токена, для корректного прохождения аутентификации с помощью функции fbGetToken необходимо внести изменения в настройки вашего приложения на Facebook. В меню приложения перейдите в раздел «Вход через Facebook». В поле «Действительные URL-адреса для перенаправления OAuth» замените текущее значение на «https://selesnow.github.io/rfacebookstat/getToken/get_token.html».
  • Добавлено 2 новые функции: fbGetBusinessManagers и fbGetAdAccountUsers, для загрузки списка доступных бизнес менеджеров, а так же для загрузки списка пользователей рекламного кабинета, так же значительно доработана функция fbGetAdAccounts (релиз версии 1.3.1 от 13 октября 2017 года).
  • В функцию fbGetMarketingStat добавлен аргумент interval, с помощью которого вы можете получить данные с разбивкой по дням, неделям, месяцам, кварталам или годам. (релиз версии 1.4.0 от 1 ноября 2017 года).
  • Функция fbGetMarketingStat теперь поддерживает работу с action_breakdowns (релиз версии 1.4.3 от 27 ноября 2017 года).

rvkstat

rvkstat– R клиент для загрузки данных из API интерфейса социальной сети Вконтакте в R.

Репозиторий rvkstat на GitHub, с полным описанием всех возможностей и функций пакета находится по ссылке.

До осени текущего года с помощью rvkstat можно было получить статистику исключительно о посещениях и статистики сообществ Вконтакте.

Доработки и релизы rvkstat за осень 2017:
  • Огромный релиз версии 2.0.0 был опубликован 19 сентября 2017 года, в общей сложности в этом релизе было добавлено более 20 новых функций для работы с рекламным кабинетом, загрузки справочников и загрузки данных о конкретном пользователи социальной сети.
  • В версии 2.0.2 был доработан процесс прохождения авторазации в API Вконтакте, в связи с чем перед обновлением пакета необходимо внести корректировки в настройке вашего приложения. (Релиз версии 2.0.2 от 29 сентября 2017 года).
  • С ноября 2017 года rvkstat теперь можно установить на Linux и Mac. (Релиз версии 2.1.0).

За тестирование версии 2.0.0 отдельное спасибо Олегу Басманову.
