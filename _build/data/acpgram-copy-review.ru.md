Адрес: https://alexey-seleznev.pro/acpgram/
Статус: архив первоначального предложения. Тексты согласованы пользователем с правками: API-ключи с конкретным примером Claude Code Remote Control, отдельный бот на машину, темы Telegram, встроенный плеер без глав и тайм-кодов, установщики GitHub, автозапуск через сервис и FAQ о long polling. ## 2. Знакомо?

- **Задача осталась в терминале.** Чтобы проверить, как работает агент, приходится возвращаться к компьютеру.
- **Долгая работа привязывает к монитору.** Агент читает код, запускает команды и вносит изменения — а вы ждёте следующего шага.
- **Разрешение нужно прямо сейчас.** Работа остановилась на подтверждении, пока вы отошли от рабочего места.

## 3. Как это работает

**От сообщения до работающего агента**

Telegram → AcpGram → Agent Client Protocol → Агент на вашем компьютере или сервере.

Вы отправляете задачу боту. AcpGram запускает выбранный движок в папке проекта и общается с ним по ACP — протоколу обмена сообщениями между клиентом и агентом через stdin/stdout. Ход работы и ответ возвращаются в Telegram.

## 4. Возможности

- **Прогресс в чате.** Следите за шагами агента, временем работы и итоговым ответом с журналом действий.
- **Подтверждения и остановка.** Разрешайте или отклоняйте запрошенные операции кнопками; прерывайте текущую задачу.
- **Четыре движка.** Переключайте агента командой `/engine`, модель и доступные параметры рассуждения — через `/model`.
- **Проекты и диалоги.** Выбирайте папку через `/project`, начинайте диалог через `/new`, возвращайтесь к истории через `/sessions`.
- **Файлы и изображения.** Отправляйте материалы вместе с задачей и получайте подготовленные агентом файлы в чат.
- **Работа в команде.** Приглашайте коллег, назначайте уровни доступа и ограничивайте доступные движки и модели.
- **История в SQLite.** Сессии, запросы, действия инструментов и разрешения записываются в локальную базу.
- **Без npm-зависимостей.** Чистый Node.js, Windows, Linux и macOS. Для установки рекомендуем Node.js 24.

## 7. Быстрый старт

**От установки до первой задачи**

Понадобятся Node.js (рекомендуем 24), установленный и авторизованный движок и токен Telegram-бота.

### 1. Создайте бота

Откройте https://t.me/BotFather, создайте бота командой `/newbot` и сохраните токен. Его попросит мастер настройки.

### 2. Установите AcpGram и запустите мастер

```sh
npm install -g acpgram
acpgram setup
```

Мастер проверит токен, определит Telegram ID администратора по сообщению боту, поможет выбрать папку проектов и движок и сохранит настройки.

### 3. Проверьте настройки

При npm-установке настройки и база находятся в `~/.acpgram` либо в каталоге `ACPGRAM_HOME`. Минимальные обязательные поля `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN
ALLOWED_USER_ID=YOUR_TELEGRAM_ID
```

По умолчанию выбран Gemini CLI. Для другого установленного движка задайте `DEFAULT_ENGINE=claude`, `codex` или `agy` через мастер или `.env`.

### 4. Отправьте первую задачу

Запустите бота:

```sh
acpgram
```

Откройте его в Telegram, отправьте `/start`, выберите проект через `/project` и напишите, что нужно сделать.

### Запуск как сервис

Linux — `systemd --user`; macOS — `launchd`; Windows — NSSM.
Общая команда установленного AcpGram:

```sh
acpgram service install
```

Проверить состояние:

```sh
acpgram service status
```

Для Windows нужен NSSM и терминал администратора. Для Linux работа после выхода из сеанса требует настройки linger по инструкции в README.

Docker — из клонированного репозитория:

```sh
git clone https://github.com/selesnow/acpgram.git
cd acpgram
cp .env.example .env
```

Заполните в `.env` токен бота, ID администратора, параметры авторизации движков и `PROJECTS_DIR`, затем запустите:

```sh
docker compose up -d --build
```

Ссылка: «Полная инструкция» → https://github.com/selesnow/acpgram#quick-start.

## 8. Безопасность и контроль

**Вы определяете, что разрешено агенту**

Код AcpGram открыт. Администратор управляет приглашениями, уровнями доступа, движками и моделями; история действий сохраняется в SQLite. В обычном режиме запросы разрешений приходят кнопками в Telegram.

База и настройки AcpGram хранятся на машине, где он установлен. Сообщения проходят через Telegram, а обработка задач зависит от выбранного движка и его провайдера.

Уровень доступа агента не заменяет песочницу: процесс работает с правами учётной записи бота, а папка проекта сама по себе не изолирует файловую систему. Полный доступ может отключать подтверждения — выдавайте его осознанно.

## 11. Частые вопросы

**Какие агенты поддерживаются?**
Claude Code, OpenAI Codex, Gemini CLI и Antigravity CLI. Достаточно установить и авторизовать один из них; остальные необязательны.

**Нужен ли публичный IP?**

**Где хранятся данные?**
При npm-установке — в `~/.acpgram` или каталоге `ACPGRAM_HOME`: настройки в `.env`, база в `data/bot.db`. Сообщения проходят через Telegram; выбранный агент использует собственный механизм обработки запросов.

**Можно ли управлять доступом коллег?**
Да. Администратор приглашает пользователей, назначает уровни доступа, разрешённые движки и модели. Уровень доступа не является изоляцией процесса от системы.

**Чем AcpGram отличается от OpenACP и telegram-acp-bot?**
AcpGram объединяет четыре движка, потоковый прогресс, выбор проектов, историю сессий и командные права в Telegram. Он написан на Node.js без npm-зависимостей. При выборе сравните актуальные README проектов: подробного сравнения аналогов здесь нет.

**Какая лицензия у проекта?**
MIT. Исходный код и текст лицензии доступны на GitHub.

**Как обновиться?**
Для npm-установки выполните `npm install -g acpgram@latest`. Если бот работает как сервис, затем выполните `acpgram service restart`. Настройки и история хранятся отдельно от установленного пакета.

**Как сообщить об ошибке?**
Создайте issue на https://github.com/selesnow/acpgram/issues. Укажите ОС, версию AcpGram, выбранный движок и шаги воспроизведения. Не прикладывайте токены и API-ключи.
