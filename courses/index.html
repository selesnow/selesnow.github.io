Не просто пользоваться LLM, а строить на R собственных AI-ассистентов.Не просто користуватися LLM, а будувати на R власних AI-асистентів.Go beyond chatting with LLMs — build your own AI assistants in R.

Курс о системной разработке AI-решений на R — без игрушечных демо. Начинаем с API разных LLM-провайдеров (ChatGPT, Claude, Gemini) и управления контекстом, затем строим веб-интерфейс AI-чата на Shiny, учим ассистента пользоваться инструментами и выполнять действия, подключаем собственную базу знаний через RAG. В итоге из ellmer, mcptools, ragnar, shinychat, querychat и mini007 собирается цельное приложение, которым можно пользоваться в реальной работе.Курс про системну розробку AI-рішень на R — без іграшкових демо. Починаємо з API різних LLM-провайдерів (ChatGPT, Claude, Gemini) та керування контекстом, потім будуємо веб-інтерфейс AI-чату на Shiny, вчимо асистента користуватися інструментами та виконувати дії, підключаємо власну базу знань через RAG. У результаті з ellmer, mcptools, ragnar, shinychat, querychat і mini007 збирається цілісний застосунок, яким можна користуватися в реальній роботі.A systematic approach to building AI solutions in R — no toy demos. You start with the APIs of different LLM providers (ChatGPT, Claude, Gemini) and context management, then build a Shiny chat interface, teach the assistant to use tools and take actions, and connect your own knowledge base via RAG. ellmer, mcptools, ragnar, shinychat, querychat and mini007 come together into a complete app you can use in real work.
